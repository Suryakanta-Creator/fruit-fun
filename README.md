# Fruitverse

A cinematic, scroll-driven fruit encyclopedia built with Next.js, TypeScript and Framer Motion.

## Experience

Fruitverse treats scrolling like moving deeper into a living rainforest: layered canopy depth, parallax atmosphere, fruit chapters, nutrition visualizations and a searchable explorer.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

Designed for Vercel deployment.
